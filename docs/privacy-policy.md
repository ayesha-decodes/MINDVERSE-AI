# Privacy policy notes for this source build

- Camera permission is optional and requested only after an explicit action.
- The current camera feature displays a local preview; no video frames are uploaded or stored by the app.
- Session data is held in browser memory and disappears when the page is reset or reloaded.
- JSON/CSV exports are created locally only after the user clicks an export control.
- The FastAPI summary endpoint validates a minimized payload but does not persist it.
- No identity recognition, facial embeddings, emotional inference or public leaderboard is implemented.

This document describes the included source code, not every possible deployment environment. Before launch, verify hosting logs, analytics, reverse proxies and any added services. Publish jurisdiction-appropriate privacy disclosures and retention/deletion procedures for the actual deployment.
